# gaussdb-etl-builder 平台变量支持与作业类型判定设计

日期：2026-08-08
状态：已确认（方案 A）

## 1. 背景与目标

上一轮改造把 `gaussdb-etl-builder` 简化为「不加载外挂文档」（知识文档、平台变量文档均不使用），需求带日期/增量语义时直接用用户给的日期。执行中发现两个问题：

1. **平台变量文档还是要支持**：ETL 作业在平台上运行，日期/增量过滤需要用平台注入的变量（如 `$ {TX_DATE}`）占位，用户希望恢复这一能力。平台变量文档一般不会变，直接**内置**到技能里即可，不用向用户询问。
2. **作业类型未区分**：建表初始化作业（一次性建表 + 装载存量/历史数据）**禁止使用平台变量**；转换作业（周期性/按日加工）才允许。必须在设计步骤之前先询问是哪种作业，避免变量误用。

目标：恢复内置平台变量文档；在 P0 增加作业类型（I/P）判定；按作业类型决定变量策略（I 禁变量、P 用 `$ {TX_DATE}`）；同步更新 SKILL.md、references 与 evals。

范围约束：**仅恢复平台变量文档，知识文档保持不支持**；I/P 判定**只控制变量可用性**，不影响目标表设计、装载方式等其他决策。

## 3. 内置平台变量文档 `references/platform-variables.md`

技能**直接读取**此文件参考，不需要用户另行提供。文档结构：

```markdown
# 平台变量

本技能**内置**的变量清单:技能直接读取此文件参考,由调度平台在作业运行时注入,SQL 里**原样保留占位符**。
若平台后续新增变量,在此追加即可。

## 变量清单

| 变量 | 含义 |
|---|---|
| `$ {TX_DATE}` | 业务日期,格式 `YYYY-MM-DD`,即**实例日期的前一天**(运行日减一天) |

## 使用约定

1. **只用于 P 转换作业**。I 初始化作业禁用平台变量(见 SKILL.md P0),日期用字面量。
2. **原样保留占位符**。生成的 SQL 中 `$ {TX_DATE}` 保持 `$ {...}` 语法,不要展开成字面日期。
3. 需求的日期语义对应到 `$ {TX_DATE}`;其他格式(去横线等)后续按平台新增变量再补,不臆造变量名。
```

要点：
- 只保留 `$ {TX_DATE}` 一个变量；删除 `${TX_DATE_NODASH}`、`${RUN_DATE}`、`${MONTH_FIRST_DAY}`；`$ {TX_DATE}` 表示业务日期（实例日期的前一天）。
- 不写死「平台不支持其他变量」之类的限制，平台变量以后可能扩展。
- 文档中 `$ {...}` 写成分离的 `$` + `{}`（`$ {TX_DATE}`），避免与技能系统模板渲染冲突；SKILL.md 正文不得硬编码 `$ {...}`。

## 4. P0 作业类型判定

P0 收尾（复述需求、收集源表、确认数据区编码之后、进入 P1 之前）新增一步：**询问作业类型**。

> "本次作业是 **初始化作业(I)** 还是 **转换作业(P)**?初始化作业指一次性建表并装载存量/历史数据;转换作业指周期性/按日跑的加工。"

判定语义（供技能参考，不硬性让用户背）：

- **I 初始化**：一次性建表 + 装载存量/历史数据 → **禁用平台变量**，日期/增量过滤用字面量或用户确认的日期。
- **P 转换**：周期性/按日加工（如「每天跑」「T+1」「增量」）→ **允许平台变量**，日期/增量过滤用 `$ {TX_DATE}` 占位。

同步调整：
- P0 的「注意」块改为：本技能**不加载知识文档**；平台变量文档为**内置** `references/platform-variables.md`，不向用户索要。
- P2「如果需求带日期/增量语义…没有平台变量文档,日期用用户指定的值」改为按 I/P 分流：
  - **I**：日期/增量过滤一律用**字面量**或用户确认的日期。
  - **P**：日期/增量过滤用 `$ {TX_DATE}` 占位，**首次出现时向用户确认一次**变量含义（如「TX_DATE 是业务日期，即实例日期的前一天，对吗」），之后沿用。

## 5. P3 生成 SQL 时的变量套用

- **P 作业**：SQL 中日期/增量过滤条件用 `$ {TX_DATE}` 占位；变量首次出现时已向用户确认，后续沿用；**原样输出占位符**，不展开成字面日期。
- **I 作业**：凡涉及日期/增量过滤，用**字面量**（用户给的日期或确认值），绝不用变量。
- 关键原则回顾补一条：**作业类型决定变量策略**——I 禁变量，P 用 `$ {TX_DATE}`。
